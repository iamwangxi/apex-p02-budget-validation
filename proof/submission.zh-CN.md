## 1. 精确主张与依赖

设 $`B`$ 是定向球面上的六个标记点。合法弧系是由有限条两两不同痕的本质弧组成的集合，各弧内部两两不相交，允许包含自环。同痕固定标记点；允许端点处旋转。按照定义 8.2，非空弧系 $`S`$ 是*纯坏*的，当且仅当每条非自环弧都在 $`S`$ 中有另一条弧与其具有相同的无序端点对；自环自动为坏弧。

类型按保定向同胚取等价，允许置换六个标记的标签。镜像仅在存在保定向同构时才合并。这些类型并非固定标记点下的无穷多个同痕类。所有受检性质在所述等价关系下均保持不变，因此下述完备性前提保证覆盖每个固定标签的弧系。

所用前提包括不相交弧系的嵌入代表、通常的本质弧与空圆盘同痕约定、独立界 $`E\leq12`$，以及广义三角剖分扩张。下文给出的拓扑论证使这一截断界可供核查。截断枚举和程序结果一致都不能独立证明这些前提；观察到的最大边数为十，不能用来论证在十二处截断的正当性。

本验证不涵盖谱序列、完整的可缩性定理、超椭圆对应字典、交数公式、除第 2 节推导的界 $`E\leq12`$ 以外的弧复形维数断言，以及几何锥引理。未执行实验 1B：新增的精确交数样本为零。有限审计止于第 9 节的预算断言；不为第 10 节提供认证。

## 2. 有限宿主空间为何足够

归约不使用任何预算结论。广义三角剖分允许自环、三角形顶点或边重复以及自折叠，参见 [Hatcher，*曲面的三角剖分*，修订版，第 1–2 页](https://pi.math.cornell.edu/~hatcher/Papers/TriangSurf.pdf)。这些属于标准拓扑前提。

**边数界。** 取 $`N`$ 为一个合法的 $`E`$ 边弧系的正则邻域，并将全部六个标记点（包括未使用的孤立标记点）纳入其中。紧致补区域 $`R_i`$ 满足

```math
\chi(N)=6-E,\qquad \sum_i\chi(R_i)=E-4,\qquad \sum_i\ell_i=2E,
```

其中，$`\ell_i`$ 对边界上的边侧计数，重复出现的边侧重复计数。这些区域均为平面型；非圆盘区域的欧拉示性数至多为零。每个圆盘区域至少有三个边侧。事实上，长度为零意味着球面上只有一个孤立顶点；长度为一则会围出非本质自环。长度为二时，两条不同的非自环边形成空二边形，因而同痕。对于围成混合双边区域的两个同基点自环，将该区域在基点处规范化为圆盘后，可得相同结论。一条自环和一条非自环不可能形成两步闭合的边界游走。同一条非自环边被遍历两次，则意味着它构成一个孤立的单边连通分量，其圆盘补区域使其他标记点无处容纳；自环的两侧则在球面上彼此分隔。因此，若 $`D`$ 为圆盘区域的数量，则

```math
E-4\leq D\leq\frac{2E}{3},\qquad E\leq12.
```

空圆盘同痕在圆盘附近进行，将一侧滑到另一侧，端点固定且允许旋转。对于同基点自环，在基点处将混合区域规范化，执行滑动，再重新粘合。这并不意味着可按所包围的标记点集合来分类任意自环的同痕类。

**扩张。** 从一个非空合法弧系出发，只要可能就加入一条与已有弧不相交的合法弧。上述独立界保证这一过程终止于一个极大弧系 $`T`$。任一未使用的标记点都可以在其所在补区域内连接到一个已有的边界顶点；新端点保证这是一个新的同痕类。如果 $`T`$ 不连通，则某个与两个连通分量相邻接的补区域允许画出一条连接两者的弧，这又是一个新类。因此，$`T`$ 使用全部六个标记点且连通，所以它在球面上的补区域都是开圆盘。

沿这些圆盘的边界游走将其切开，保留重复标签与重复边。本质性和弧的互异性排除了空单边形和空二边形；若某个面将同一条边遍历两次，则整个连通图只能是这一条边。若一个面至少有四条边，就在不相邻的角之间画一条对角线。重复标签可能使该对角线成为自环，而这是允许的。若声称该对角线非本质，则它会切出一个空圆盘，其中原有的边本身都必须是非本质自环。若声称该对角线与已有边同痕，则它会与已有边形成空二边形；对于同基点自环，则会形成规范化后的空混合圆盘。该圆盘内任一原有边要么是非本质自环，要么与其边界边平行。合法性排除了这些可能；如果内部没有原有边，那么这两个角原本就是相邻的。因此，该对角线合法，与极大性矛盾。这就是广义三角剖分扩张的局部内容，包括边界标签重复和自折叠的情形。

因此，宿主满足

```math
V=6,\qquad 3F=2E,\qquad V-E+F=2,
\qquad E=12,\quad F=8.
```

反之，一个具有六个顶点且所有面均为三角形的连通球面嵌入图是合法的。如果一条边或一对边围出空单边形或空二边形，将其规范化为一个边界长度为 $`b\in\{1,2\}`$、无内部顶点的三角剖分圆盘。欧拉示性数与三角形边侧计数将要求内部边数为 $`b-3<0`$。同基点自环之间规范化后的空混合区域也由同一计数处理。因此，每个宿主子集都是合法的，而每个合法弧系都作为至少一个宿主的子集出现。这一归约不使用引理 9.11、9.14、9.15 或推论 9.16 中的任何结论。

## 3. 生成全部定向宿主

以下规范允许不依赖任何特定规范标号库进行重建。

对偶宿主是具有八个顶点、十二条边的连通三正则球面嵌入图，允许自环、重边和桥。选取一棵生成树，将其余五条边切成十个枝梢，并以其中一个枝梢为根。所得定向树是一棵具有八个内部节点的有序满二叉树。其邻域与外部均为圆盘，因此被切开的边构成按外部边界顺序排列的十个枝梢的非交叉完美匹配。反之，每棵这样的树及其匹配都可在外部圆盘中粘合，得到一个三正则球面嵌入图。因此，所有目标嵌入图都会出现，无须依赖翻转图的连通性。

递归生成有序树：

```math
\mathcal T_0=\{\text{empty}\},\qquad
\mathcal T_n=\bigcup_{i=0}^{n-1}
\{(L,R):L\in\mathcal T_i,\ R\in\mathcal T_{n-1-i}\}.
```

在每个内部节点按（父、左、右）的循环顺序分配三个半边，定义置换 $`\tau`$。用 $`\alpha`$ 沿树边配对父、子槽位；暂时固定根节点的父槽位和每个空子槽位。按 $`\tau\circ\alpha`$ 的唯一轨道读取这十个枝梢。递归生成所有非交叉匹配：将位置零依次与每个奇数位置配对，再独立匹配剩下的两个偶数长度区间。用匹配对替换固定的枝梢，并令

```math
\sigma=\tau\circ\alpha,\qquad
\varphi=\sigma\circ\alpha=\tau.
```

这里，$`\alpha`$ 配对边，$`\sigma`$ 的循环是顶点，$`\varphi`$ 的循环是三角形面。对每个构造检查这些置换恒等式、连通性以及顶点循环数为六。原始构造共有

```math
C_8C_5=1430\cdot42=60{,}060
```

个。去重方法是依次以 24 个半边中的每一个为根，按固定后继顺序 $`[\alpha(d),\sigma(d)]`$ 进行广度优先重标号，再取拼接后的重标号置换数组的最小值。编码相等恰好对应定向嵌入图同构：定根同构保持该遍历，而相等的数组给出反向对应。绝不将 $`\sigma`$ 替换为其逆。结果为 191 个宿主。

在每个宿主中，按每对中较小的半边，为构成其十二条边的半边对排序，并遍历从 1 到 4095 的每个非空位掩码。仅通过统计选中的非自环端点对来检验纯坏性；每个端点对必须至少出现两次。每条选中的自环各自构成一个对象。不得按已用标记点数、间隙数、自由性、干净性或任何预算结论剪枝。

## 4. 重建区域并检验断言

对于任一保留边集 $`Q`$，按如下方式计算 $`R(Q)`$。从八个宿主三角形出发，跨越每条不在 $`Q`$ 中的边进行合并，包括自粘合。每个连通分量都是一个开补区域。用三类互不相交的原子表示它：

- 其中的开三角形；
- 与这些三角形邻接且不在 $`Q`$ 中的开边；
- 未被 $`Q`$ 使用、且所有邻接三角形都属于该连通分量的标记顶点。

未使用顶点的所有邻接扇区都会合并，因为它的所有邻接边都不在 $`Q`$ 中。一个已用顶点位于某区域的边界上，当且仅当该顶点处某个选中半边的一侧是该区域。将 $`\sigma`$ 的每个顶点循环限制在保留的半边上，得到 $`\sigma_Q`$。$`\sigma_Q\circ\alpha`$ 的循环就是边界游走；将每条边界游走归入其邻接宿主三角形所在的连通分量。保留每个区域的全部边界游走。当 $`Q`$ 不连通时，区域未必是圆盘。内部标记点数 $`k`$ 就是顶点原子的数量。

保留所有边界分组和未使用标记点，便保留了不连通情形下的嵌套关系。一条狭缝边可以改变开区域，而不改变其三角形，因此所有相等性与不交性检验都使用完整的三类原子集合。

还在宿主上直接检查合法性，并在保留的代表上再次检查。在 $`R(\{e\})`$ 中，自环的每一侧都必须有其他标记点。在 $`R(\{e,f\})`$ 中，端点相同的两条非自环边的两侧都必须有标记点。两个同基点自环不得形成无标记点的混合二边形，其边界各取每个自环的一侧。这些是独立于预算断言的本质性与空圆盘检验；宿主子集继承合法性。

对于纯坏弧系 $`S`$，对象包括单个自环以及端点对相同的完整重复非自环族。对象 $`O`$ 的间隙是区域 $`R(O)`$。另一对象 $`O'`$ 包含于间隙 $`g`$ 的闭包中，当且仅当 $`O'`$ 的每个开边原子都属于 $`g`$；此时它的端点自动属于该闭包。如果没有其他对象满足这一检验，则该间隙是自由的。这是直接按定义计算，而不假定引理 9.8 成立。在计算 $`k(g)`$ 时，纳入间隙内的所有标记点，包括被其他对象使用的标记点。

对每个间隙，将其完整原子集合与 $`R(S)`$ 中的每个区域作比较，以判定它是否为整个弧系的面。设 $`X(g)`$ 为其实际的边界标记点集合，$`\mathcal F`$ 为 $`S`$ 的重复非自环端点对集合。通过检查 $`X(g)`$ 中每一对不同标记点是否都属于 $`\mathcal F`$ 来检验干净性；不得假定边界上至多有两个标记点。一个好面必须同时满足：是整个弧系的面、是自由间隙、干净，且 $`k(g)\in\{1,2\}`$。

记录的谓词为：

1. 引理 9.11：至少存在两个自由间隙，其完整原子集合两两不相交，且每个自由间隙都等于整个弧系的一个面。
2. 引理 9.14：每个自由间隙都满足 $`k(g)\geq1`$。
3. 引理 9.15：至少存在一个好面。
4. 推论 9.16：实际已用标记点数 $`V'`$（即 $`S`$ 所使用的标记点数）满足 $`V'\leq4`$。
5. 辅助推论 9.13：每个自由间隙都是干净的；单独检查此项以作诊断。

## 5. 精确类型去重与独立检查

对每个子集构造一个四色有向图，其节点分别为六个标记点节点、选中半边节点、选中边节点和补区域节点。每个半边指向其端点标记、所属边、侧区域（其所在宿主 $`\varphi`$ 面所属的连通分量），以及同一顶点处的下一个选中半边。每个未使用标记点指向包含它的区域。四种目标颜色区分半边的四种关系。

将规范证书定义为：在每种颜色内部的所有节点置换中，取字典序最小的邻接矩阵，并在前面附上四种颜色的节点数。原则上，暴力规范化已经足够；实现使用 `pynauty==2.8.8.1`。边的归属关系恢复 $`\alpha`$，半边后继恢复定向循环次序，区域邻接关系将全部边界游走分组，并定位未使用标记点。这些数据确定正则邻域及其亏格为零的补曲面，从而在所述等价关系下确定定向嵌入。特别是，对于不连通的情形，不能仅凭各连通分量自身循环次序的无序列表进行分类。

完整证书判定相等性；SHA-256 只用于给记录加标签。不同的规范标号实现可以对相同的类型、谓词和计数产生不同的字节与标识符。

从一个显式八面体出发的独立 Whitehead 变换闭包执行了 1,924 次转移。独立的规范化确认得到相同的 191 个宿主，且双向集合差均为空。树／枝梢论证提供覆盖保证；仅有列表一致并不能提供这一保证。

主谓词使用并查集和半边边界游走；另一实现使用对偶图 BFS 及其自己的原子／对象计算。两者共用定义和编码约定，不共用区域或谓词函数。去重前，一项补充审计检查了全部 11,504 个纯坏见证，比较了十个字段：合并及分开的 9.11 谓词、9.13、9.14、9.15、9.16、自由间隙数、好面数和 $`V'`$。全部 115,040 次比较均一致；每项结论均通过。

审计还检查了原子守恒、欧拉关系、658 次完整记录重建、658 次确定性半边重标号，以及五个人工构造的正／负合法性示例。它调用现有谓词，并非第三套独立实现或宿主生成器。

**跨模型重新实现与宿主普查。** 在本稿冻结后，来自不同模型系列的 Claude 审读了归约，并编写了两个仅使用标准库的脚本，没有导入上述任何模块。第一个脚本独立于所有生成器检查宿主列表：191 个宿主都是有效、两两不同构的定向三角剖分，且

```math
\sum_{h}\frac{24}{|\mathrm{Aut}^+(h)|}=4096,
```

其中，$`\mathrm{Aut}^+(h)`$ 是保定向嵌入图自同构群，通过定根重标号计算。右侧是具有八个顶点的有根平面三正则嵌入图的数量（OEIS A002005，$`a(4)`$）。每个有效宿主都贡献一个正数，而所有定向宿主的贡献之和为 $`a(4)`$，因此没有遗漏。对具有两个和四个顶点、允许自环与重边的有根三正则球面嵌入图进行暴力计数，重现了 $`a(1)=4`$ 和 $`a(2)=32`$，确认该数列计数的恰好是这些对偶嵌入图。

第二个脚本是直接依据定义 8.2 和 9.1–9.4 编写的第三套谓词实现。它在全部 782,145 个子集上重现了 11,504 个纯坏见证、其边数分布 $`(504,1218,2121,2607,2375,1599,765,255,54,6,0,0)`$ 和已用标记点数分布 $`(1310,5916,3718,560,0,0)`$，9.11、9.13、9.14、9.15 和 9.16 均无失败。它直接重新检查宿主合法性：1,465 次自环与重复端点对检验未发现空单边形或空二边形。对照检验表明这些谓词具有区分能力：459 个见证没有满足 $`k=1`$ 的好面，560 个使用四个标记点，7,515 个不存在三个两两不相交的自由间隙。它与上述实现仅共用宿主数据和论文定义。
