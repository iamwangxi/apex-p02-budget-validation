# Apex 论文 02：六点预算的穷举验证

这个聚焦的资料包支持对 Apex Intelligence 的 [*亏格二情形下，两两至多相交一次的曲线所构成的复形是可缩的*](https://math.apexin.net/papers/curve-complex-genus-two.pdf)（日期为 2026 年九月 11 日）中的引理 9.11、9.14、9.15 和推论 9.16 进行有限核查。推论 9.13 也作为辅助谓词接受检验。目标 PDF 共 35 页，SHA-256 为 `d1eadd01f94e9af17ee9f5fb2ee1b05b326430f37296309fd9417340ea366fd4`。

本工作的贡献是穷举式组合核查及其可复现性证据。本文不将原论文中的预算陈述和标准曲面拓扑输入主张为新定理。投稿正文的版本为 **v1.3**；它引用了 [apex-p02-budget-validation](https://github.com/iamwangxi/apex-p02-budget-validation) 的 **v1.2** 仓库快照。`v1.2` 标签固定了该快照。后续正文或文档改动需要新的提交和新版本；不得移动现有标签。

## 准确范围

658 种非空纯坏弧系类型是在允许置换标记点标签的情况下，按六标记点球面的保定向同胚分类的。镜像并未被有意视为同一类。该计算不枚举逐一固定标记点时无限多的同痕类。

完备性依赖嵌入弧系代表、标准的本质性／空圆盘同痕事实、独立的边数上界 `E <= 12`，以及广义三角剖分扩张。这些归约论证载于投稿正文；截断后的有限计算不能独立确立自身的截断界，也不能认证弧复形的所有维数。

| 核查项目 | 结果 |
|---|---:|
| 树／枝梢构造 | 60,060 |
| 定向三角剖分宿主 | 191 |
| 非空宿主子集 | 782,145 |
| 仅因并非纯坏而被排除 | 770,641 |
| 纯坏宿主见证 | 11,504 |
| 定向类型 | 658 |
| 去重前的谓词字段比较 | 115,040 |
| 未通过的预算谓词 | 0 |

宿主比较使用从显式八面体出发、单独实现的 Whitehead 变换闭包。第二套谓词实现使用对偶图 BFS，而非主实现的并查集区域算法。两者共用数学编码模型和定义。补充审计调用这两套实现；它并非第三套独立的谓词实现。由 Claude 根据原论文定义另行编写的第三套实现重现了全部 11,504 个纯坏见证，且谓词失败数为零；独立于生成器的计数核查表明，191 个宿主按 24/|Aut+| 加权求和得到 4096，即八顶点有根平面三正则嵌入图的数量（OEIS A002005）。两者都仅使用标准库，且不导入本资料包的其他模块。

本资料包不验证原始谱序列、完整的可缩性定理、超椭圆对应字典、交数公式或几何锥引理。实验 1B 未执行：新的精确交数样本为零。此处既不需要也不主张其他证明路线。

## 如何阅读宿主证书

`alpha` 将半边配对成边。`sigma` 的六个循环是标记顶点；八个三角形面循环遵循 `d -> sigma[alpha[d]]`，相应检查函数为 `validate_map`，位于 `code/triangulations.py`。

这些宿主是广义三角剖分。度为 1 的标记顶点位于自折三角形内；也存在由同一标记点上的三条自环围成的三角形。

这些宿主全部合法。已记录的跨模型输出包含 1,465 项直接合法性检查，违规数为 0（`certificates/claude-crosscheck.txt`）。
